Before You Play

1
First-time loading

The first time you launch Vice City, around 600 MB of game data will be downloaded. Future visits will load much faster once the data is cached.

2
Get the controls

Tap the game screen once after loading to activate the game controls.

3
Joystick not working?

Use the Release Cursor option from the game menu to unlock the cursor and get the on-screen joystick working properly.

Read these instructions before continuing. Vice City may still be preparing its game data in the background.
